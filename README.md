# CyberCore Zsh Extensions


<!-- CYBERCORE-SEVEN-EXTENSIONS -->
## Extensions

### Workflow and safety
- **[zsh-workflow-guardian](extensions/zsh-workflow-guardian/README.md)** — Workflow checkpoints and warnings around potentially destructive commands.
- **[zsh-command-auditor](extensions/zsh-command-auditor/README.md)** — Command and exit-status audit logging.
- **[zsh-git-sentinel](extensions/zsh-git-sentinel/README.md)** — Read-only Git state diagnostics and warnings.

### Context and productivity
- **[zsh-context-aware](extensions/zsh-context-aware/README.md)** — Project, language, environment, and tooling detection.
- **[zsh-memory-lane](extensions/zsh-memory-lane/README.md)** — Search command history and save reusable command recipes.
- **[zsh-intent-bridge](extensions/zsh-intent-bridge/README.md)** — Natural-language intent translated into proposed commands for review.

### Session continuity
- **[zsh-session-continuity](extensions/zsh-session-continuity/README.md)** — Record objectives, progress, decisions, and handoff notes.
